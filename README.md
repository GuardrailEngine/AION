# AION

Safety decision system with scoped confirmation channel.

[![AION Tests](https://github.com/GuardrailEngine/AION/actions/workflows/aion-tests.yml/badge.svg)](https://github.com/GuardrailEngine/AION/actions/workflows/aion-tests.yml)

## What it is

AION separates proposal from execution. A model proposes, 
Core decides, nothing executes without verification, 
constitutional context, and valid external confirmation.
